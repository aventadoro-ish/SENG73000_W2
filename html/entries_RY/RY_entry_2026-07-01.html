Summary

Began designing the PCB by researching available load-cell amplifier ICs, selecting replacement components, and creating the initial schematic for the load-cell interface.

← Return to Logbook Cover Page

Objective

Begin development of the custom PCB and determine the primary analog front-end architecture.

Research

Compared several load-cell amplifier ICs after discovering the HX711 was unavailable. Reviewed datasheets, package options, communication interfaces, and firmware support. Later learned that the HX711 would have to involve I2C and that wouldn't be necesary for this project. Using MCP6N11 would be simpler.

Design Decisions

  • Selected the NAU7802 ADC.
  • Verified DigiKey availability.
  • Confirmed ESP32-S3 I²C compatibility.
  • Reviewed software libraries.

Initial Schematic

Created the first schematic connecting the load cell, power circuitry, and ESP32-S3 interface.

Next Steps

  • Complete signal conditioning
  • Review schematic
  • Share the files on Github and the group
