Populating the FC Boards

Today, I worked with my team on populating the Floor Controller (FC) boards. We had four PCBs in total, each containing a large number of surface-mount components. Since there were many components to place, we developed an organized workflow to distribute the work efficiently across the team.

Solder Paste Application

We first applied solder paste to the PCBs using a stencil. This allowed us to apply solder paste consistently to the required pads across all four boards before beginning component placement.

Tracking with the Population Status Spreadsheet

We then organized the SMD components into passive components and active components, such as integrated circuits (ICs). To keep track of the population process, Matvey created an Excel spreadsheet called PCB Population Status Batch 2. The spreadsheet listed the component designators and component numbers from the schematic, as well as which team member was responsible for placing each component and on which PCB.

Dividing the Work

We focused on productivity by assigning each team member a group of components rather than having everyone work on one PCB at a time. Each member would place all of the components assigned to them across the four PCBs before rotating the boards to the next team member. This reduced the amount of time spent switching between component types and helped maintain a consistent population process across all four boards.

Results

The process worked very efficiently. Within approximately four hours, we completed the component population of the FC boards and prepared them for the reflow oven. This was a useful example of how organizing component assignments and dividing repetitive assembly tasks can significantly improve productivity when working with multiple PCBs.
