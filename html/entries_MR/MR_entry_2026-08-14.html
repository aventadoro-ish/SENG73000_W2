PCB Rework and Assembly

Nick, Rita, and I began manually correcting and completing the newly reflowed PCBs. The work included inspecting solder joints, removing solder bridges, installing bottom-side components, and adding the remaining configuration parts and connectors.

  • Rita repaired the soldering on Floor Controller unit 3 and installed the bottom-side LEDs and 470 Ω resistors.
  • Nick repaired solder bridges on Floor Controller unit 4, installed 0 Ω resistors in place of the unavailable fuse components, assembled the bottom-side components, and added one pin header.
  • I repaired solder bridges on Car Controller unit 3, installed 0 Ω resistors as temporary fuse replacements, assembled the bottom-side components, and installed several JST-PH connectors.

I completed the remaining CC #3 assembly work that was possible with the available components and performed partial testing of the board to check its basic operation.

CAN Demonstration Code

I prepared CAN communication demonstration firmware for the custom controllers. The demonstration was intended to show both daisy-chained CAN communication through the USB-C connectors and power delivery through the same controller interconnection scheme.

Virtual-Door Toggle Fix

I corrected the Supervisory Controller's virtual-door toggle behaviour when virtual commands interacted with physical door-state updates. The fix improved synchronization between the two control sources so that a physical door change would not leave the virtual-door state or subsequent command handling inconsistent.
