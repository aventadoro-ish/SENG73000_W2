Short Team Meeting about Phase 2 plans

I invited Rita and Nick to have a short chat about our team's plans for Phase 2 of the project. This meeting took place after a Software Engineering midterm, so we kept it short, and I simply introduced the ideas I had for what we can do during Phase 2. Most of my ideas focused on custom PCB development.

    • Custom PCB development
I also kept in mind the primary deliverables for Phase 2 and proposed contingency plans for hitting the main deliverables even if PCB development is delayed.
  • Software features:
    • Server on RPi
    • Website controls for the elevator
    • Authentication and authorization
    Software development is happening alongside PCB development and is not dependant on PCB completion. No contingency plan needed.
  • Audio signalling for visually-impaired elevator users.
    Project Charter only requires 1 speaker system to be connected to SC. This can be implemented with an I2S audio amplifier and a small speaker I have on hand in case PCB is not implemented on time.
Additionally, we need to catch up on 2 features from Phase 1 that were moved to Phase 2.
  • ToF sensor for EC
  • LCD screen for EC
Since, EC is allowed to use Arduino framework libraries, the addition of these features will not take long. I will also have to design mounts for these components.
