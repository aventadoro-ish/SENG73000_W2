Finalized SC FSM for Phase 1 requirements

Since Rita never delivered the version of FSM with support for CC door toggle switch, I added that functionality to prepare for the demo tomorrow. The implementation and changes to physical circuit of the door toggle switch (as described in 2026-06-19 logbook entry), required me to also modify code for CC.
The door toggle switch required a change to the elevator CAN bus communication protocol, which previously wasn't properly documented. I created a table defining this protocol.

CAN ID
[Hex]		 Transmitter Recipient(s) DLC Byte 0
7 6 5 4 3 2 1 0
0x100 SC EC 1 SC_EN SC_FloorReq
0x101 EC ALL 1 EC_EN EC_Pos
0x200 CC SC 1 CC_EN CC_FloorReq
0x201 F1 SC 1 F1_Req
0x202 F2 SC 1 F2_Req
0x203 F3 SC 1 F3_Req
Fields Description Value
SC_EN Supervisory Controller Enable 0 - disabled
1 - enabled
SC_FloorReq SC request to EC to move the elevator cabin to a given floor 0 - INVALID
1-3 - floors 1-3
EC_EN Elevator Controller Enable 0 - disabled
1 - enabled
EC_Pos EC reports current position of the elevator cabin 0 - moving
1-3 - stopped at floor 1-3
CC_EN Car Controller Enable. Informs SC if door is closed (enable) or open (disable) 0 - door is open, and cabin MUST NOT be moved
1 - door is closed, and cabin may be moved
CC_FloorReq CC request to SC to move elevator cabin to a certain floor 0 - no request
1-3 - floors 1-3
F1_Req Floor Controller requesting the elevator cabin to floor 1 0 - INVALID
1 - request cabin to this floor
F2_Req Floor Controller requesting the elevator cabin to floor 2 0 - INVALID
1 - request cabin to this floor
F3_Req Floor Controller requesting the elevator cabin to floor 3 0 - INVALID
1 - request cabin to this floor
This table is also available on CAN Protocol page.

Recorded Phase 1 demo video

I shot and edited the Phase 1 demo video showcasing:

  • System-wide CAN communication
  • SC and EC console outputs demonstrating CAN frame filtering on both controllers
  • Door toggle switch as a safety measure
  • Elevator moving up and down to the requested floor
  • Full operation sequence
    1. FCx requests the cabin to a floor x
    2. SC receiving the request and waiting until CC door is closed
    3. CC sending door closed bit
    4. SC issuing command to EC to move the cabin
    5. EC informs all nodes about cabin moving
    6. EC informing all nods about cabin reaching the requested floor
    7. CC "opening" door and informing SC that doors are open
    8. SC blocking all floor requests until CC sends doors closed frame
    9. CC requesting a floor with doors closed
    10. SC issuing command to EC to move the cabin
  • Floor request queuing and dequeuing
