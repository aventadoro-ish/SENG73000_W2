Rita's SC FSM testing

Rita delivered an initial untested version of SC FSM implementation. Since she had to leave the lab early, I tested the code for her.
To do this initial testing, I used git to transfer the source files and test the program on RPi, which proved to be very time-consuming and tedious. This setup required me to:

  1. run on PC
    git add .
  2. run on PC
    git commit -m "message"
  3. run on PC
    git push
  4. run on RPi
    git pull
  5. run on RPi
    make clean
  6. run on RPi
    make
  7. run on RPi
    ./main
This workflow needs to be improved significantly to make SC development easier with a headless setup.

The testing revealed several bugs and errors in the code, but, fortunately, all of the bugs were caught by the compiler as warnings, so troubleshooting was relatively quick.
As the result of this, all parts of the system moved together for the first time.

While functional, this version of the FSM does not support door toggle switch monitoring. Additionally, there aren't enough console prints to demonstrate CAN bus message filtering. I will ask Rita to implement this functionality.
Additionally, new motor pulley wheel needs to be installed to proceed with testing.
