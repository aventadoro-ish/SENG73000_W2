FSM Changes for Phase 2

The Raspberry Pi Supervisory Controller FSM needs to be improved to satisfy the Phase 2 requirements and prepare the project for the Custom Floor Controller PCBs. The required code changes are as follows:

  • For Phase 2, the FSM must support Sabbath mode, maintenance lockout, and commands read from the database.
  • To support the new PCBs, the FSM must handle additional floors, implement a scheduling algorithm for those floors, distinguish between upward and downward requests, and process data frames containing accelerometer and load-cell readings.
  • The existing sleep() calls must be removed.

For now, I will focus on the functionality required for Phase 2.
