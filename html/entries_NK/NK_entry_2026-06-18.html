Toggle switch code implemented:

Implemented the function seen below for tthe toggle switch.


// function for door switch on car controller
void doorSwitch(void){

// only run the code if it's the CC_BOARD and not Floor controllers
#if SELECTED_BOARD == CC_BOARD

	// set a helper variable to 0. Use static to keep it between function calls.
	static GPIO_PinState lastSwitchState = GPIO_PIN_RESET;
	// grab current switch state
	GPIO_PinState currentSwitchState = HAL_GPIO_ReadPin(CC_Switch_GPIO_Port, CC_Switch_Pin);

	// if there was a change (switch flipped)
	if(currentSwitchState != lastSwitchState)
	{
		// reset the variable
		lastSwitchState = currentSwitchState;

		// if the switch is ON
		if(currentSwitchState == GPIO_PIN_SET)
		{
			// switch is ON = doors open = no movement allowed. Send CAN message of 0b100 or 0x04
			CAN_ByteTransmit(MY_ID, CAB_BLOCK);
			LED_BlinkStart(&greenLedTimer, 200);
		}
	}
#endif
}

It first checked what board it was running on (SELECTED_BOARD) since running it on a floor controller would be a waste of resources (it doesn't have a toggle switch lol). After, it grabbed the current GPIO state and stored it in a temporary variable before comparing if it was toggle (current vs last state logic). Lastly, if the switch was on, it would call CAN_ByteTransmit() to send the data out. This message had the message ID of 0x200 was it was the car controller sending it out (refer to CAN protocol). The data bit it sent was 0b100 or just four. This is because 1-3 were reserved for floor requests, and the 0th bit was used to show the toggle switch being off.

Prism JS added for code formatting

Prism JS is a JS script that highlights code based off of the language used. In the above example, it was used to colour the function and format it into a code-block. I believe there's a way to refine it or make it our own using various .CSS classes, but that will be left for phase 2.

Here is how the script is called in the head of HTML files:


<link rel="stylesheet" href="https://cdnjs.cloudflare.com/ajax/libs/prism/1.29.0/themes/prism.min.css">

Then, to call the script to add the function of it, it is imported as such:


<!-- call the main JS library: -->
<script src="https://cdnjs.cloudflare.com/ajax/libs/prism/1.29.0/prism.min.js"></script>

<!-- language auto-loader -->
<script src="https://cdn.jsdelivr.net/npm/prismjs@1.29.0/plugins/autoloader/prism-autoloader.min.js"></script>

<!-- alternatively and as a backup, I load C manually as well since autoload gave me some small issues with formatting. -->
<script src="https://cdnjs.cloudflare.com/ajax/libs/prism/1.29.0/components/prism-c.min.js"></script>

Lastly, to use it within the HTML file, it can be done like so (using C for this example):


<pre class="code-block language-c"><code class="language-c"></code>
< !-- code pasted in here -->
if(something) {
	// do something
}
</code><pre>
