Week 11

CAN Diagnostics Page

Entry 1 - 2026-07-20

  • Configured the Raspberry Pi 4 to communicate with the MAX98357A I²S audio amplifier.
  • Modified the firmware configuration to enable the I²S interface and verified successful hardware detection through ALSA.
  • Repaired loose speaker connections and confirmed successful audio playback using test audio.
  • Prepared the floor announcement audio system for future integration with the Supervisory Controller finite state machine.
  • Began planning a diagnostics webpage to monitor and display CAN network information.

Entry 2 - 2026-07-23

  • Received the Elevator Diagnostics Page specification and reviewed the existing PHP implementation for reference.
  • Developed the initial elevator_diagnostics.php page to decode and display CAN request information from the database.
  • Implemented administrator-only authentication and organized CAN message decoding using a lookup array.
  • Created client-side search, sorting, and pagination using vanilla JavaScript.
  • Added supporting CSS while maintaining consistency with the existing website design.

Entry 3 - 2026-07-24

  • Verified the correct production SQL schema and investigated the database connection between the Apache VM and Raspberry Pi.
  • Added computed CAN byte decoding based on the documented CAN protocol specification.
  • Expanded the diagnostics page with a second table displaying detailed elevator request information.
  • Refactored the JavaScript implementation to support multiple searchable and sortable diagnostics tables.
  • Designed the can_message_log database table to support future logging of live CAN bus traffic.
